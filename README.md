# portfolio

Personal portfolio site, deployed to GitHub Pages.

Live at: https://podrozniasia.github.io/portfolio/

## Editing

Plain HTML and CSS: edit `index.html` and `style.css`. Preview locally by opening `index.html` in a browser.

## Deployment

Every push to `main` deploys automatically through `.github/workflows/deploy.yml`.
You can also trigger it manually from the repo's **Actions** tab.
